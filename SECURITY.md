# Security Policy

## Supported Versions

Security fixes are applied to the latest released version on the default branch of [HuolalaTech/arkflow](https://github.com/HuolalaTech/arkflow). Older releases may not receive backports.

## Reporting a Vulnerability

Please **do not** open a public GitHub Issue for security vulnerabilities.

Report privately via GitHub Security Advisories: **Security → Report a vulnerability** on the repository.

Include:

- Affected version / commit
- Reproduction steps or proof-of-concept (private)
- Impact assessment if known

We aim to acknowledge reports within **7 business days**. Please allow reasonable time for investigation and coordinated disclosure before public discussion.

## Scope Notes

ArkFlow is an Agent Skills package. It may invoke local DevEco Studio / HarmonyOS SDK tools on the user's machine. Vulnerabilities that belong entirely to those upstream products should be reported upstream; a heads-up is appreciated if a bundled script or default path is affected.
